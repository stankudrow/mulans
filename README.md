# mulans

Mulans = Multi-Language Translator - многоязычный переводчик.

## Содержание

- [Обзор](#обзор)
  - [LLM](#llm)

### Обзор

Это "потомцевый" (pet) проект - местный/локальный переводчик, к которому можно прикрутить разные интерфейсы для взаимодействия с программой - возможно ради этого проект и разрабатывался.

#### LLM

Этот раздел оставил в качестве памятки, ибо игры с БЯЗ - большими языковыми моделями - для меня в новинку.

Сперва я хотел стянуть модель через [ollama][ollama], например: `ollama pull qwen3.5:4b`. Но из-за геополитики стянуть не удалось из-за провала TLS рукопожатия, поэтому пришлось скачать модель на свою машину и в итоге выбрал [Qwen3.5-4B-abliterated-Q4_K_M][llm] - возможно Qwen переборна для этой задачи, но пусть так для моего "слабого" ноута и можно остановиться дабы не погружаться в долгие поиски и разбирательства.

Затем понадобилось прописать [Modelfile](./assets/Modelfile.example) для сборки модели: `ollama create qwen3-trans -f /path/to/Modelfile`. И это хватает. Можно в терминале запустить модель и пообщаться с ней: `ollama run qwen3-trans`.

[ollama]: https://ollama.com/
[llm]: https://huggingface.co/mradermacher/Huihui-Qwen3.5-4B-abliterated-GGUF
